## Ranked defects

1. **High — restored child selections lose the selected tab.** Fix: on mount, resolve every saved child item through the same tab-writing path as `selectSidebarItem`/`applySkillsToolsSection`, including a distinct Tools mapping, before replacing `selectionRaw` with the parent.

2. **High — NextGen navigation does not navigate to NextGen.** Fix: add a typed Capabilities child destination that sets Overview plus `CapabilitiesDisclosurePreference.nextGenKey = true`, and route both `.openNextGenRequest` and `/nextgen` through it.

3. **Medium — the multimodal review notification can open Mac integration instead of Trust.** Fix: make the notification route explicitly write `trust` to `shell.tab.Trust` before selecting `.trust`.

4. **Medium — Cmd-K cannot directly reach Cognition or Inspector.** Fix: add route-only palette rows for `.cognition` and `.inspector`, filtered through the effective developer-surfaces policy.

5. **Low — the Navigate menu contradicts the new-shell developer policy.** It checks raw `showDeveloperSurfaces`, so Knowledge Graph is hidden there while the resolver exposes it in the new shell; fix the conditional to use `NativeAgentShellPreference.developerSurfacesShown` ([NativeAgentApp.swift:318](Sources/NativeAgentApp/NativeAgentApp.swift:318)).

6. **Low — twelve `SetupRoute` destinations are dead after removal of the Advanced door.** Only Mac integration, Telegram, and iPhone have `NavigationLink` producers; Minds, Providers, Trust, Personality, Connectors, Capabilities, Knowledge Graph, Dreams, Diagnostics, Notifications, MCP, and Skills & Tools remain mounted in an unreachable switch. Remove those cases/views or restore deliberate producers ([SetupView.swift:27](Sources/NativeAgentApp/SetupView.swift:27), [SetupView.swift:168](Sources/NativeAgentApp/SetupView.swift:168), [SetupView.swift:395](Sources/NativeAgentApp/SetupView.swift:395), [SetupView.swift:526](Sources/NativeAgentApp/SetupView.swift:526)).

Telegram, iPhone, and Mac integration are deliberately duplicated mounts: each is available from Settings and as a rail tab; they share the same underlying view/state rather than duplicating storage. The direct child cases in `ContentView` and `SkillsToolsView` are reachable only through the classic shell or compatibility deep links, which is required by the kill switch rather than dead new-shell navigation.

No files were edited and no build or tests were run. Existing unrelated modifications in `MacChatTurnCard.swift` and `MacChatTurnCardTests.swift` were untouched.
