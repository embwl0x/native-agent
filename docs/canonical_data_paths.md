# Canonical data paths — Path C

Single source of truth for every on-disk file the Swift-native runtime reads or
writes. Every resolver in `Modules/NativeAgentCore/Sources/` and
`Sources/NativeAgentApp/` MUST land on a path in the CANONICAL table below; the
LEGACY table lists retired paths that must not be read or recreated at runtime.

## CANONICAL

| Path                                 | Rationale                                                                                              |
| ------------------------------------ | ------------------------------------------------------------------------------------------------------ |
| `<dataRoot>/chat/sessions.json`      | Session index (id, title, lastTurnAt) — chat list view reads this.                                     |
| `<dataRoot>/chat/messages/<sessionId>.jsonl` | Append-only per-session message log; replay + scroll-back come from here.                     |
| `<dataRoot>/memory/memory.sqlite`    | MemoryV2 truth — memories, proposals, tombstones. GRDB. Owned by `MemoryStorage`.                      |
| `<personaRoot>/USER.md`              | The user-doc projection MemoryV2 owns. Generated by `UserMDGenerator`; read by the normal persona compiler. |
| `<dataRoot>/telegram/config.json`    | Per-feature Telegram config (token, allowed ids, enabled). Read+write here.                            |
| `<dataRoot>/providers/registry.json` | Provider catalog (display name, capabilities).                                                         |
| `<dataRoot>/providers/active.json`   | Active provider per surface (chat/Workshop/dream/...).                                                 |
| `<dataRoot>/providers/surfaces.json` | Per-surface model preferences.                                                                         |
| `<dataRoot>/codex_home/auth.json`    | Codex/OpenAI OAuth/PKCE token store.                                                                   |
| `<dataRoot>/context/context.sqlite`  | Rebuildable Fluid Context generations and source descriptors.                                          |
| `<dataRoot>/cognition/cognition.sqlite` | CognitiveSubstrate continuity and receipts; never a second MemoryV2 store.                           |
| `<dataRoot>/cognition/organism_state.json` | Bounded optional Organism Kernel continuity.                                                     |
| `<dataRoot>/workshop/`               | Desk/Workshop execution state, triggers, migrations, and unified receipts.                             |
| `<dataRoot>/turn_traces/<day>.jsonl` | Bounded authoritative per-turn inspection ledger.                                                      |

## LEGACY (backup-only, never read at runtime)

| Path                                          | Replaced by                          | Notes                                                                     |
| --------------------------------------------- | ------------------------------------ | ------------------------------------------------------------------------- |
| `<dataRoot>/memory/memory.json`               | `memory/memory.sqlite`               | Drained by `MemoryV2Migrator` on first launch; preserved for the 30-day backup window. No code path reads this anymore. |
| `<dataRoot>/memory/USER.md`                   | `<personaRoot>/USER.md`              | Old persona-root fallback. Resolvers no longer fall back here.            |
| `<dataRoot>/persona/Agent/USER.md`            | `<personaRoot>/USER.md`              | Retired split MemoryV2 projection. USER belongs with the rest of Agent's persona docs. |
| `<dataRoot>/config/config.json` `["telegram"]`| `telegram/config.json`               | Migrated once on first `loadFromDisk`; never read after the copy.         |
