# NativeAgent 0.6.17

You can always tell what your agent is doing, and the window stays light however long it works.

- Never left guessing: the status box in chat lists the last steps your agent
  finished above the one it is on; a step that runs past thirty seconds says
  your agent is still on it and that nothing is stuck, instead of reporting no
  movement
- A window that stays light: the interface no longer grows in memory while a
  turn streams (a long session could reach many gigabytes), and opening the
  Make or Screen pane no longer freezes it
- Steps you can follow: each step keeps one row from start to finish, the
  running one shows that it is running, and waiting on the model is no longer
  listed as a step
- Quiet sooner: after a reply the processor settles in seconds instead of
  about a minute
- Fewer model calls: an action can carry your agent's closing words, so when it
  comes back as expected the turn ends there instead of calling the model again
- Large files and results: a read of chosen lines returns those lines, and a
  long value is read in pages that join without gaps
- Lower cost on Claude models: the part of a request that changes every turn is
  cached for five minutes instead of paid for at the one-hour rate
- Memory: what is worth keeping from a turn is judged one moment at a time, and
  turns you were not part of are judged when your agent is idle
- Models: Fable 5.2 and GPT-6-Luna appear in the model list
