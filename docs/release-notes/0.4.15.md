# NativeAgent 0.4.15

The agent plugs into other agents. Say "connect to Codex" and it does the
setup itself, shows you one card, and proves the link with a real message. It
speaks A2A 1.0, has an MCP door, and can work with Grok Bot. Plus honest
failure reports and the fixes from five full passes over the tree.

## Other agents

- **Connect by asking.** "Connect to Codex" (or Claude Code, or another agent
  on this Mac) in chat: the agent finds that agent's settings, shows one card
  with exactly what it will add, writes it with a backup, and checks the link
  with a real message. "Disconnect" puts those settings back byte for byte.
- **A2A 1.0** (and 0.3) in both directions over JSON-RPC, HTTP+JSON and gRPC,
  checked against the official a2a-python SDK: every operation, streaming and
  push notifications. The agent card is served on this Mac only.
- **An MCP door** for MCP clients, and `nativeagent-link`, a small signed
  helper other agents run to reach the agent or hand a reply back.
- **Grok Bot.** Connect opens the Bot's own chat, asks it to create one
  webhook routine, and reads the routine's address and key from Grok Bot's
  Routines panel into the Keychain. After that a question goes out by webhook
  and Grok's answer comes back into the same conversation as one attributed
  turn. Grok Bot comes to the front briefly during setup.
- **Other agents cannot act for you.** Once a turn has read another agent's
  words, anything it would change asks you first.
- Command-line agents that speak ACP can be contacts too. This is built and
  not yet driven against an installed ACP agent.

## Honest outcomes

- A provider failure (quota, rate limit, sign-in, model not available) shows
  its real cause and whether any work ran: nothing ran, ran partly, or
  outcome unknown. The same report reaches other agents that called in.
- A tool call that did not run says which of four things happened: a card is
  waiting for you, this surface cannot ask, you said no, or no approval can
  lift it.
- Large results arrive in whole sections with the relevant part first, and an
  exact way to get the rest.

## Chat composer

- Model, Think and Trust share one shell above the composer row. It slides to
  the word you reached for and grows to fit; a provider's models are part of
  the same shell.
- The context ring opens a receipt of what the last turn actually assembled,
  each part with its size.
- The agent can work its own composer and settings, with a receipt for each
  change. Trust stays yours: it opens and reads, and nothing sets it.

## A second opinion

- One Providers row takes a Jev (TypeSafe) key and turns on five advisory
  checks. Everything they find is a hint; nothing grants, denies or blocks.

## Fixes

- The approval strip above the composer takes a mouse click again.
- A macOS folder-access prompt can no longer hold a turn.
- Stop stops: a late follow-up no longer starts another response.
- Pressing Done in Providers no longer discards an unsaved key.
- Upgrades: an unreadable pin list no longer archives pinned conversations;
  an older build no longer overwrites newer reminder settings.
- iPhone: an approval is final only once the Mac accepts it; automatic pairing
  no longer undoes an unpair you chose.
- Security: MCP redirects cannot carry session keys to another origin;
  connection keys are scrubbed from agent error replies; a crafted search
  filename cannot expose protected file contents.
- Text streams keep showing activity while the model works.
- Tool arguments accept the ordinary spellings of a value.
- The morning brief ships off on a fresh install; a fresh install reads as the
  Work trust preset; dream runs file under the right day.
- About 250,000 lines of unused code removed.
