# NativeAgent 0.6.19

Cards you can count on, memories that come home, and an agent that never asks you about something that cannot work.

## Cards

- Every card in the chat takes your click: key fields take a paste, and every
  button responds. Before, a click could select the card as text instead
- A card you answer always lets your agent carry on, whichever app started the
  conversation, and its reply is written once
- A model you pick on a card for one request is the model that request runs on
- A settled card leaves nothing behind in the chat, and its record says what
  was answered, by whom, and what it changed
- No more red error lines at the top of a chat

## Memory

- Bring an older agent's memories home: point your agent at an archive or an
  old data folder and approve one card. Each memory comes back through your
  agent's own memory, keeping when it was learned and who said it. Nothing is
  brought in twice, and memories that were deleted stay deleted
- A memory keeps the date it was really learned, even when another agent told it
- Reconnecting an agent changes nothing you set: what it told your agent stays
  credited to it, and its Trust switch stays the way you left it

## Your agent asks less, and only when it can act

- A request that cannot work is refused before any card: no prompt on the Mac,
  your phone or Telegram, and the refusal names what would work
- Every refusal is recorded the same way, so your agent's history shows plainly
  that nothing ran
- An approved action that takes a while shows as running until it finishes
- Messaging another agent by its name works; a name that is not listed says so
  and lists who is

## Messages to other agents

- A message your agent sends and waits on is answered only by the reply that
  names it; a second message never cancels the first, and a reply that arrives
  as the app quits is handed over once after it opens again

## Desk, window and Mac

- A free board on the Desk: you and your agent draw on the same board, and each
  edit is saved as a new version your agent can read
- The window follows your agent: when it opens a page to show you something,
  the window goes there, and anything you do comes first
- Quit always quits, even while your agent is thinking, and leaves one window
- When the screen changes under a step, your agent looks again only in the
  window it started in; if that window closed, it touches nothing
- Watches: news from a watch opens a thought of its own, and cancelling a
  scheduled read finds the exact one you named

## Correction to 0.6.18

- The 0.6.18 notes said OpenRouter now gets its output allowance in its own
  field. It does not: no allowance is sent to OpenRouter, so each model's own
  ceiling applies

Requires an Apple silicon Mac running macOS 26 or newer.
