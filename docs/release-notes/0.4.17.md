# NativeAgent 0.4.17

A steadier agent that works well with others. Agents on your Mac stay in one
continuing conversation, the agent's tool calls come back with real results,
web search is back, and long chats keep their thread on every model.

## Other agents

- **Muse** (Meta) joins the agents you can connect: one side chat in the
  Muse app that keeps its context from message to message.
- **Grok** stays connected: a missed reply no longer blocks the next message,
  and late replies still arrive.
- **Hermes and other ACP agents** continue their session across messages.
- Disconnecting an agent needs its exact contact, so a similar name can never
  remove the wrong one.
- Nothing is typed into another app while the Mac is locked.

## Chat

- Newer models: Claude Opus 5.5, GPT-6 Sol and GPT-6 Luna.
- Tool calls on Claude sign-in come back with real results. A reply can no
  longer describe results before the tools have run.
- Every model follows the same rule for long chats: the conversation compacts
  at the limit you set in Settings or at 60% of the model's window, whichever
  is smaller, and the agent sees the whole conversation up to that point.
- **Chat compaction** is back in Settings.
- Asking to "read my email", "text Mom" or "search the latest news" finds the
  right tool the first time.

## Web search

- Web search works again, with a news category and a time range for today's
  stories.

## Telegram and iPhone

- Replies read cleanly on Telegram: no stray asterisks, links as text, and no
  working notes left above the answer. The "Queued" message disappears once
  the turn starts.
- Urgent alerts reach Telegram when that is where you last were.
- Error cards say what happened in plain words.

## Helpers

- Helpers run at a clock time: daily, weekdays or weekly, at the hour you pick.
- Run once no longer moves the next scheduled run.

## Quieter and safer

- Desk reminders wait for the end of quiet hours instead of being dropped.
- Memory never merges a correction that changes a number or a "not".
- A first launch that is interrupted can no longer split your old data.
- The classic sidebar is retired.
