# NativeAgent 0.4.9

Setup is easier to follow, with the same capabilities. The message box selects
text again, and the Chrome extension is included with the app.

## Setup

- Onboarding starts with your name and the agent's name. Expand the optional
  overview to see what the agent can help with.
- Setup copy says what you get, not which files the app writes. If the app cannot
  read your accounts, it says so and offers Retry; what you typed stays put.
- The app asks for speech recognition permission when you first use voice, not
  at launch.
- A browser sign-in that stalls can be cancelled and retried from the app.
- First chat without an account points at signing in, not at copying tokens.
- The agent's inner life (reflection, moods, its own hour) starts on after setup
  and a working account; you can switch any of it off.

## Trust

- Four presets lead the page: Safe, Work mode, Builder, Full Mac. The saved state
  is always named, and a custom policy still says which access mode is in effect.
- Controls that apply immediately are separate from the policy draft you save.
  Clicking a preset never discards an unsaved draft.

## Providers

- The connected account leads, with Manage beside it. Every sign-in and API key
  route is visible. Optional model choices for individual activities are tucked
  under a summary that distinguishes custom choices from defaults.

## Chrome

- The Chrome extension is included with the app. Set up Chrome opens its folder
  and Chrome's extensions page, with installation steps.
- Settings recovery names the cause and offers the real action.

## Pairing

- The Mac leads with automatic pairing for the same Apple Account; the manual key
  is secondary and the unusable QR code is gone. The phone checks for the Mac
  before offering manual correction.

## Chat

- Dragging inside the message box selects text again instead of moving the window.
- Image failures point at the visible setting or action that fixes them.
- Voice notes from Telegram wait for permission before they are used.

## The agent's Studio

- An optional working shelf holds up to three references chosen by the agent,
  each with a sentence about what to carry forward. After image creation, an
  invitation makes it easier to open the work and decide whether to keep it in
  Studio; nothing is saved there automatically.

## Under the hood

- The image worker runs with an allowlisted environment, a read-only sandbox and
  a delimited prompt.
- Google connector setup explains the advanced path and offers Mac Calendar and
  Mail as the simple one.
- Diagnostics recovery opens Providers directly.
