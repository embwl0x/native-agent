# NativeAgent 0.6.18

Your agent's models stay current, its permissions are easier to read, and a new Mac starts without false alarms.

- Models that stay current: each account lists what its provider offers today,
  and Refresh asks again. A model newer than this build can still be chosen,
  and an account offers only what its provider actually listed
- Trust you can read at a glance: a lock marks each thing your agent asks you
  about first, each app's Read and Write sit side by side on one row, and a
  section you open shows every row
- A calmer window: switches and controls no longer take the system's accent
  colour, so the only colour that means something is the one that says your
  agent is waiting on you
- A clean start: on a Mac that never set up search, iCloud or a phone, Doctor
  says off instead of failed, and a fresh install no longer shows alarms for
  things that are not wrong
- Telegram voice notes need nothing installed: the Mac reads them itself
- Fewer broken calls on a Claude sign-in: a call is read to its real end, and
  when one does break, the correction says what went wrong
- A hand that grows: an action your agent has used is ready from its next
  turn, its own abilities included
- Long writes are visible: while your agent writes something large, the status
  box says what it is writing and how big it is
- Receipts that keep to themselves: a receipt for Mail, Messages or a device
  read shows that it happened and how large it was, not what was in it
- Stop always stops, even when its marker file cannot be read
- Screen pictures: one unreadable element no longer withholds the whole picture
- A notification can carry a subtitle

Requires an Apple silicon Mac running macOS 26 or newer.
