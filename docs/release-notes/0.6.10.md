# NativeAgent 0.6.10

The second day with a brand-new agent on a real Mac: everything found, fixed before the cut.

- Their conversation with a connected agent is one session, like yours with them:
  every door's turn runs in it, a message from the agent says who it is and
  that it is its own, their reads show both directions with each send's state, a
  reply that comes back wakes their into the same thread, Claude Code names the
  conversation on its side ("NativeAgent · <their name> · <label>"), and
  messages queued when they restarted resume in order before anything new
- Who said a line is what its own row attests, stamped once when the row is
  written from the transport's verified identity, and every place that shows a
  contact's words reads that stamp: a trusted contact's words never steer their,
  an untrusted one's steer exactly the turn that reads them, and words nothing
  attested count as another agent's
- They finds any agent that speaks a protocol, not only the ones their recipe
  book names: an A2A card on any local port, an MCP server in any app's
  settings, an ACP program on your PATH; opening the Agents page only reads,
  and a found program runs only when you ask their to discover it, under the
  same rule a send to it uses
- A grant macOS applies only at launch (Accessibility, Full Disk Access,
  Screen Recording, Input Monitoring) no longer settles its card on a probe
  that agrees too early: the card says it is on and takes effect after they
  restarts, and they restarts when you tell their to
- Doctor says what is: a provider you signed in to but have not used yet is
  "saved", not "needs sign-in"; an off or not-needed reading settles an owed
  repair instead of holding it red; an unreadable Slack config is a fault with
  its file, not "off"; owed rows read under their current status; a remedy is
  one sentence; the path status rolls up only the path checks; the window is
  this launch; the page names the run it shows and whether one is still
  running
- A read is not the send before it: an agent conversation's read reports the
  read and the send's state stays with the send; a message to Claude Desktop
  or Claude Code that was not handed over says "not sent", never "held"; a
  call made while NativeAgent restarts waits for it and otherwise says nothing
  was sent; a Mac app's page says its Automation access as macOS grants it now
