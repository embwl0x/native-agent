# NativeAgent 0.4.11

The agent reviewed its own skill shelf and kept what it uses. Turns carry fewer
tools. And a long list of readouts stopped claiming more than they knew.

## The room

- The page ground is a charcoal slate in the same family as the cards, with a
  smaller, softer warm glow in the corner the lamp sits in. Before, the lamp's
  wash covered so much of the page that the ground read green on one side and
  purple on the other, and the cards sat on top of it instead of in it.
- Cards in dark rooms are a soft silver-grey. The navy they had was a workaround
  for the old, larger lamp, which turned neutral cards brown; the smaller lamp
  does not, so the workaround went.
- Today's **Waiting for you** card is the same surface as every other card. Its
  priority is the heading and the button, not a separate green-grey panel.
- Small text on cards — Today's times, Providers' field labels — is one step
  brighter, and the waiting heading in light rooms is a darker teal, so every
  line on Today and Providers clears 4.5:1 against the card it sits on.

## Today

- A waiting card with no reason line shows the thing itself. A **REM growth
  lesson** now shows the lesson under its title, so you can read what you are
  approving.

## Skills

- The agent read all thirty-six skills it had and decided, row by row, what to
  keep. Thirteen bodies were rewritten with its corrections, sixteen were
  retired, and five that said the same thing as another were merged into the body
  that said it best. On the maintainer's install that leaves sixteen of its own
  bodies alongside the two skills it wrote for itself at runtime.
- The commonest reason for a rewrite: the body was build advice addressed to a
  developer, naming surfaces that no longer exist, rather than a procedure the
  agent owns.
- Four engineering checklists are gone from the shelf and replaced by one the
  agent wrote in its own words, **Operator acceptance**: what to check after an
  install. Read the live state before forming an opinion, never the changelog;
  walk the author's list item by item; hunt the fields that lie — a zero timing,
  a fresh timestamp on an old measurement; for sign-in, the decisive test is a
  clean re-auth with no cached token; say what could not be tested from its seat.
- Skills the agent writes for itself sit in its own runtime shelf and behave like
  any other skill. The two standing ones on the maintainer's install are a
  delegation loop for running Desk campaigns, and **Liquid Glass judgment** — how
  to compose and judge a native surface, measure text against the ground it
  actually sits on, and check the accessibility settings that change it.
- Saving a skill whose text has no heading now gets a heading from the skill's
  name instead of a refusal. That refusal is why Liquid Glass judgment had to be
  written twice: the first attempt, a week earlier, was rejected and the text was
  lost. The rest of the hygiene rules still refuse, loudly.
- Nothing was deleted. Retired bodies are archived unchanged: engineering ones
  under `docs/skills-archive/`, the agent's own identity bodies beside its
  persona, both for reference only and neither loaded by the app.

## Tools

- Twenty tools ride every request, and the tools of a mounted MCP server ride
  with them automatically. Everything else is lazy: it joins a turn when
  the agent loads it or when the turn's intent clearly calls for it, and it
  leaves again after two turns without a real call.
- No family is resident any more. Under Full Mac, the file and system tools load
  on intent like everything else, instead of putting twenty-five schemas on every
  one-word turn.
- A confident preload brings in the matched group only. The bridge shortcut that
  pulled three groups in whenever a bridge message mentioned a file is gone.
- A tool dropped for being idle is not immediately re-offered; a real call or an
  explicit load brings it straight back. Nothing is ever removed from the
  catalog — retired is not removed.
- Four classes of tool failure that looked like the agent's fault were the
  schema's, and each was silently costing whole turns:
  - The Workshop's three recording tools refused every single call for ten days,
    because the harness adds a field and the tools demanded an exact match. The
    agent reworded its arguments seventy-two times and never learned why.
  - Handing work to a builder required a Desk item id the agent had no way to
    know, so it invented one and the send died. That field is optional now; an
    id that no longer exists is ignored and the message still goes, with a
    receipt saying what was dropped.
  - Saving a memory with topics attached only worked for corrections. Topics are
    optional everywhere now, and never a reason to lose the memory.
  - Asking to look at NativeAgent's own window is refused — reading our own
    interface that way deadlocks the app — and the refusal now says so, and says
    what to read instead, rather than reading as a capability failure.
- The exact agreed behaviour is one page: [Tool loading](../TOOL_LOADING.md).

## Bots

- Scheduled bot runs now sit behind the master Autonomy switch, the same switch
  that governs the Workshop. Turn Autonomy off and no timer fires. **Run once**
  is you asking, so it still runs.
- **Continue in Chat** carries the bot's own contract: its model, its reasoning
  effort, and its approval rule. Typing in a bot's session no longer silently
  swaps in Chat's model.
- A bot's card headline is the first line of prose its reply actually opens with,
  never a row lifted out of a table.
- Bots get the same Fluid Context and memory recall as any other turn, so a
  standing helper knows what the agent knows.
- A cadence job is no longer handed a progress tool that could only refuse it.

## Workshop

- A session that ends without recording what it did is written down as
  **blocked**, with the reason named — a turn that ended is not a turn that
  progressed. If the recording calls themselves failed, the receipt says which.
  A later valid report supersedes earlier recording failures.

## Desk

- A **now** or **next** row that cannot actually move — blocked, deferred, or
  waiting on a held parent — reads **held**. The line still says why. Nothing is
  stored; the hold lifting restores the row's own status.
- The GitHub fold counts what it holds: how many are still open and how many are
  closed, instead of calling closed work "moving on its own".
- The schedule fold counts the jobs that actually run. Paused jobs are counted
  separately, as paused.

## Memories

- The **Deleted** tab shows the proposals you rejected. It was reading the
  pending list, so it said nothing had ever been rejected while hundreds of
  rejected rows sat in the store.
- A memory with no recorded source no longer claims you shared it.
- The **active** count applies the same lifecycle rule the list does, so the
  summary and the rows agree on one number.
- Correcting a pending statement marks the old one superseded rather than
  rejected, and a superseded row is no longer offered back for review.
- Engineering instructions stay out of personal conversations. A memory has to
  name build work to be treated as build material.
- The **Knowledge graph** tab's entity list fills the page again. It had been a
  two-row strip at the foot of a blank page.

## Providers

- An account whose access token has expired says so: *signed in, access expired,
  refresh unproven until the next chat*. It no longer reads as simply ready.
- Per-activity model choices are three rows instead of fifteen: **Chat**,
  **Work**, and **Memory and mind**. Storage is still per surface, and a surface
  that belongs to no group keeps its own row.
- The dreaming and REM lanes are captioned **Dreams** and **REM** in the
  Memory and mind group, not "Memory review" and "Personal growth".

## Diagnostics

- Doctor takes its measurement clock before the first check runs and publishes it
  separately from the time the file was written, so the page can say how old the
  findings are rather than how recently they were saved. The first refresh after
  a completed turn measures fresh instead of replaying a cached answer.

## Inner life

- Caring is an event, not a temperature. The agent appraises an exchange and
  registers a caring moment when there is one; one encounter gives one dose, and
  it fades on the wall clock over about three days whether the week was busy or
  quiet. It softens how the agent takes things personally and nothing else.
- Every appraisal leaves a one-line receipt, including when it declined to
  register anything — an abstention and a failure are now different records.
- A moment the agent chose not to keep says so. "Nothing found" and "the
  extractor could not run" are no longer the same silence.

## Memory across the bridge

- Conversations that arrive over the local Codex and Claude Code bridge are
  ordinary turns: the sender is named, memory lanes run, and a bridge-started
  session is digested like any other conversation.
- The reply no longer waits behind that work. Remembering starts once the answer
  is written down and is never waited on, keeps the turn it came from, and stays
  attributable in the turn inspector afterwards.

## iPhone

- **Activity** waits for each section's own data before showing a zero. An empty
  list used to read as "clear" before anything had arrived.
- Freshness is per group. A Desk badge shows when the Desk was delivered, not
  when any sync last touched anything, and a refresh reports its own success.
- A Desk summary the Mac had to cut says so, and the history section says how
  many items the Mac published out of how many exist.
- The tab bar draws all five tabs as outlined glyphs at one weight, selected
  included — less ink, finer edges.
