# NativeAgent 0.4.7

This release adds background research bots for your agent, refreshes the
iPhone app, and reduces the Mac download size.

## Standing bots

Your agent can now create small background jobs to keep up with a topic,
research a question, or check for changes, on a schedule or just once. The bot
capability ships in this release; a dedicated Bots page is still in
development.

- Bots gather information from public web sources and supported read-only
  tools, then write reports in the format your agent requests.
- Reports are dated and retain sources, useful changes, and gaps in coverage,
  including when nothing changed, a check was only partly completed, or a
  source could not be checked.
- Each bot keeps notes between runs so it can build on previous findings.
  Results wait for your agent to review when needed; bots do not generate
  notifications.
- Bots operate within Trust Center permissions and spending limits. No bots
  are created by default.

## iPhone

- A quieter look across every screen, closer to the Mac app: calm surfaces,
  glass only on navigation, one accent for selection and actions, readable
  status text, and improved layouts for larger text.
- Stop replaces Send while a reply is streaming. Approvals show an honest
  pending state when iCloud is offline. Pairing reads as setup steps, and
  Settings says what is wrong and offers one recovery action.
- Stop and Steer reach a running chat over iCloud, a received answer is never
  overwritten by a late send error, and delayed uploads are no longer skipped.

## New-install defaults

- Memory in Fast mode, the knowledge graph, and dreams are now enabled on
  fresh installs. Switch off what you do not want.

## A smaller download

- The large memory-search model is no longer inside the app. A lightweight
  model works immediately while the larger one downloads in the background.
  Updates are smaller when a delta is available.

## Slack, Telegram and the bridge

- Slack: more reliable conversations across restarts, with clearer errors
  when a file cannot be read.
- Telegram: long conversations retain better summaries, and approval status
  is clearer. Progress messages describe the task.
- Bridge clients see live progress during a long turn, not only the result.

## Security

- Credentials quoted inside JSON are scrubbed from traces. Calling an external
  connector from the Capabilities screen goes through the Trust Center,
  requests approval when required, and is audited. Replies reflected back
  through iCloud Drive or CloudKit are refused before they can act as
  commands.

## Reliability

- Memory recall and delegation status do less repeated work, and the iPhone
  no longer stalls while waiting on a snapshot.
