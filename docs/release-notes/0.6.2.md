# NativeAgent 0.6.2

A cleaner first run, and fewer rounds on the asks that used to cost
several.

## First run

- Health checks wait until setup is finished, so nothing asks for anything
  before you have picked a provider or named your agent.
- On a Mac where the agent uses a ChatGPT sign-in it found in the Codex
  CLI, the search row says plainly that general search needs its own
  NativeAgent sign-in and that no search has been measured, instead of
  asking you to fix something.
- Continue on the account step is visibly unavailable until a model is
  chosen, and says so.

## Fewer rounds

- A chat search that has more results hands back the exact next call; a
  list given to any single-value argument of a read runs once per value,
  and the app says which arguments take one.
- One read of the Mac Integration page answers what the agent can reach:
  supported routes, effective permission, connection readiness and verified
  access, each labelled, with nothing probed.
- Finding an action by intent ranks what the action does and the surfaces it
  covers above incidental page words.
- Reading another conversation's history is a background read, separate from
  moving your screen; the chat page says how.
