# NativeAgent 0.4.5

This release repairs the cross-surface regressions found after the large 0.4.4
integration and makes Full Mac operation dependable again without narrowing
what Full Mac YOLO is allowed to do.

## iPhone chat continuity

- Keep a newly created iPhone chat on its own session instead of snapping back
  to an older conversation when a reply arrives.
- Project completed replies into the visible transcript even when the push
  notification arrives first.
- Restore usable Normal/Fast controls and stop unavailable Fast mode from being
  selected implicitly.
- Serialize simultaneous approval decisions so approved inbox items settle
  once and disappear correctly.
- Keep the compact live-status label on one line.

## Full Mac YOLO continuity

- Apply the prompt-free Full Mac authority contract consistently across Mac,
  Telegram, iOS, Slack, local bridge, lifecycle, workflow, and native tool
  paths.
- Preserve ordinary approval behavior outside Full Mac YOLO and retain hard
  refusals for untrusted origins, missing integrations, protected data, and
  macOS privacy permissions.
- Keep developer reinstalls on the signed app-bundle launch path so an existing
  macOS Accessibility grant is not lost through direct executable fallback.

## Runtime and evaluation repairs

- Align Mac tool discovery with lazy loading and make native-tool coverage
  exhaustive.
- Accept schema-valid empty memory scopes and stabilize strict-provider tool
  placeholders.
- Repair changed-eval ownership mappings and run the affected iOS regressions
  through the focused evaluation runner on Bash 3.2.
- Expand runtime and evaluation contract coverage around the repaired paths.

The final live audit used Agent through the authenticated local bridge to
exercise the complete 180-tool catalog. Safe temporary mutations were cleaned
up, unavailable external integrations failed closed, and no NativeAgent
approval prompt appeared under Full Mac YOLO. Apple privacy permissions remain
a separate operating-system boundary.
