# NativeAgent 0.4.12

The Providers picker is the rule now: every activity runs on its group's choice, the first
account you connect fills everything, and nothing picks a model behind your back. Plus a
faster chat, bots that wake on events and settle into cards, and a sign-in fix.

## Providers

- **Sign in with Anthropic** can now complete. The browser hand-back uses the
  `nativeagent://` link, and the app never declared that link to macOS, so the
  sheet opened the browser and then waited forever. The scheme is registered in
  the app bundle now.
- The Anthropic account sheet carries **Or run `claude setup-token` in Terminal and paste the key here**
  beside the browser button. Make one with `claude setup-token` or at
  console.anthropic.com under Settings then OAuth, paste, Save. It used to sit
  in the collapsed fold under the account list where nobody found it.
- The ChatGPT account sheet shows its **Re-authenticate** button outright
  instead of behind a chevron labelled "Reconnect ChatGPT account". Signing in
  again there renews the same token the Codex CLI row uses.

## Dreams

- Dreams, REM, and creative exploration run on the **Memory and mind** model.
  They used to carry a cheap model of their own; a ChatGPT account does not serve
  it, so on an install whose only connected account was a ChatGPT one every dream
  ended as **dream needs retry** and no diary entry was ever written. Every
  activity in a group now resolves to that group's account and model — the
  group's override when it has one, Chat's when it has none — so no lane can be
  aimed at a model its account cannot serve. Work behaves the same way, and the
  first account you connect populates Chat, so a fresh install runs everything on
  that first pick whatever provider it is.
- A dream that fails now names the reason in the notification — the provider's
  own line, such as "model is not supported when using Codex with a ChatGPT
  account" — instead of only saying that something needs attention.

## Providers (models)

- **GPT-5.4** and **GPT-5.4 mini** are gone from the model picker; they are no
  longer carried. A saved pick of a model that is no longer in the catalog stops
  counting as a pick: that activity goes back to its group's choice, and the
  group's caption says so (**Same as Chat**, or the group's override). Nothing is
  quietly swapped for a different model.
- A bot always runs on the model it was made with. The account, model and Think
  level are chosen when the bot is made and are part of it — there is no
  "same as Chat" for bots any more. A bot saved earlier without one reads
  **Choose a model** on its card and does not run until a model is set.

## Bots

- A scheduled run that never happened now says so. A bot's card and its detail
  read **Missed Sep 12 at 9:00 AM** with the reason in plain words: the Mac was
  asleep, the app was closed, Autonomy was off, the queue was busy, the daily
  token ceiling was reached, or "not run" when nothing better is known. Before
  this, an occurrence the Mac slept through left no trace at all.
- The Desk's schedule fold counts missed occurrences apart from what runs and
  what is paused, and lists each one with its bot's name.
- A missed occurrence is a record, not a retry. Nothing runs late by itself —
  the Autonomy switch still decides every unattended run — and the next
  occurrence is scheduled as usual. The record survives relaunch, and survives
  editing the bot.
- A bot can now wake **On an event**, beside Manual and the schedules. Two
  sources this round: a new GitHub issue or pull request on a repository the
  GitHub connector already tracks, and a Slack message in a channel the Slack
  connector already receives. Give the editor the repository as `owner/repo`, or
  the Slack channel ID — Slack delivers an ID rather than a name, so the field
  takes `C0123ABCD` and says where to copy it — plus a keyword when only some
  events should wake the bot.
- An event wakes a bot once: the GitHub key is claimed on disk before delivery,
  and the Slack claim is persisted in the inbound delivery journal, so a restart,
  a retry or a recovery pass repeats nothing.
- The event text is the input for that run, so the brief can act on what
  arrived instead of re-fetching it.
- The card says **Wakes on: GitHub · owner/repo** and the last event that
  arrived.
- An event is unattended spend, so it passes the same master Autonomy switch a
  scheduled run passes. With Autonomy off the event is recorded as held and
  nothing runs. Per-run limits, the daily ceiling and one-run-at-a-time are
  unchanged.
- A finished run is now one settled card at the top of the bot's page instead of
  a reply bubble sitting on the session transcript. The card carries the first
  line of the reply, when the run happened and how long it took, one word for how
  it ended (Completed, Stopped, Failed, Blocked), the model the run used, and any
  file or link the reply produced.
- **Open the reply** expands the full text inside the card. **Continue in Chat**
  and **Run once** stay where they were.
- The last five runs stack newest-first; the full session stays under
  **Session · messages and tool activity** below the cards.
- A run now records the model it actually ran on, so a card stays honest after
  the bot's choice changes. A run recorded before 0.4.12 reads **Model not
  recorded**.
## Chat

- **See what the agent is looking at.** While the agent drives the Mac, the
  working card above the message box carries a small picture of the last screen
  the agent took, with a line naming the verb in flight. Click it for a larger
  view, or reach it with Tab and press Space; Escape closes it. Until now the
  only sign of where the agent was looking arrived after each verb, in the
  receipt.
- **The line never claims more than the picture shows.** The agent looks at the
  screen several times to find a button before it clicks anything, so while
  that is happening the picture shows the button unclicked and the line reads
  "About to click Save". Only after the click, over the fresh look the agent
  takes to check its own work, does the line become "Clicked Save" — or "Could
  not click Save".
- It costs nothing when the Mac is not involved: the card is unchanged on every
  turn that uses no Mac verbs, and the picture is the frame the verb had already
  captured — nothing is captured for the pane, and nothing is captured on a
  timer.
- The picture is held in memory for the length of the turn and then dropped —
  when the turn's intake closes, when the next turn opens, and when a turn is
  discarded. Only the latest frame is kept. It is never written into the
  conversation or any receipt, never saved to disk, never sent to the AI
  provider, and never becomes memory.
  Secure fields — password, passcode, and one-time-code boxes — are painted out
  of it, by the same test that already keeps those words out of what the agent
  reads, and a password box in a web page counts: it is recognised by its
  accessibility role, its subrole, its label, the app's own secret verdict, or
  simply by showing bullets instead of characters. Only secure fields are
  hidden; an ordinary text box beside a password box stays readable.
