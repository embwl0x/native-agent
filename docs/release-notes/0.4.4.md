# NativeAgent 0.4.4

This release brings together improvements across computer use, memory,
conversation, delegation, and everyday reliability.

## More natural computer use

- Address visible objects by their names, shapes, colors, and spatial relations.
- Read bounded views of controls and on-screen readouts without duplicating
  the full screen context.
- Use coordinated key holds, right-button gestures, paced drags, fine scrolling,
  and clearer pointer feedback through the existing native controls.
- Track moving targets with measured timing and bounded confirmation. Uncertain
  or obstructed targets still refuse unsafe input; this is not a claim of
  general game-playing capability.

## Better recall without crowded context

- More relevant, dated recall with compact history pages and exact identities.
- Recover longer remembered facts through bounded, version-checked pages.
- Keep corrections, deletions, repeated observations, and skill recall aligned
  with their canonical stores.
- Keep work information available on demand without adding unsolicited work
  summaries to ordinary conversation.

## More dependable conversations and delegation

- Preserve tool evidence, interruption state, and chronology across chat
  surfaces, retries, forks, and compaction.
- Keep queued Telegram messages and retries on the same durable queue path.
- Preserve accepted builder requests, explicit resume intent, worker settings,
  retained results, and exact delegated-message lookup.
- Report unavailable, incomplete, blocked, and uncertain outcomes honestly,
  without silently replaying potentially completed work.
- Improve conversation and personality guidance while retaining the configured
  persona as the authority.

## Integrated reliability

- Reduce unnecessary background and screen-processing work.
- Improve health reporting, tool readiness, lifecycle cleanup, and evaluation
  execution receipts.
- Retire disconnected code and reconcile its timer inventory.
- Recover cleanly from stale Chrome extension contexts after an extension reload.
- Restore repeated Activity navigation and keep UI checks aligned with current
  destinations.
- Include Chrome extension and deterministic iOS-release fixtures in the
  canonical gate, isolate test data-root handling, and distinguish coverage
  inventory from fresh execution evidence.
- Add a documentation entry map for current ownership, repository layout, and
  validation boundaries.

Existing Full Mac access and Trust Center modes remain in place. Apple privacy
permissions still apply. Personal memories, credentials, and persona state are
not part of the public source or installer.
