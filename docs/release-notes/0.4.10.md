# NativeAgent 0.4.10

The agent can keep standing helpers of its own, every page is faster to open,
and the settings rooms read as one sheet of glass.

## Bots

- A new Bots page. The agent makes a bot for anything it wants watched, gathered
  or worked on, for you or for itself. A bot needs only a name and a brief; it
  keeps its own conversation, uses the agent's tools under the current Trust
  policy, and lives until the agent deletes it.
- Leave the model blank and a bot runs on the same route as Chat. Choose any
  connected account, model, Think level and Fast setting when you want to. An
  account that cannot use tools says so before it answers.
- Timing is manual, twice daily, daily, every N hours, or a custom schedule.
  Run once and Pause are always available. Per-run and daily limits are yours
  to set; blank means the defaults.
- Each bot is a card: a small mark whose light breathes only while it runs, the
  state in words, the brief, what it last said, and whether it runs again. Open
  a bot for its dated replies, newest first, with the session folded beneath
  and a way to continue in Chat.

## Trust

- Trust is four cards: Safe, Work mode, Builder, Full Mac. Each does exactly
  what it says. The summary beneath is read from your settings as they are.
- Choosing a preset keeps an unsaved draft; the form says Unsaved changes and
  Save keeps them.

## Providers

- Model choices for individual activities are always in view, one line each:
  Provider, Model, Think, Fast. Use default restores inheritance from Chat.
- Settings left by an earlier version are ignored quietly.

## Chat

- Tab leaves the message box: tool receipts and the sidebar are reachable by
  keyboard.
- Tool receipts lead with the outcome. A partial result says what was not
  created and why; the raw reason stays in Details.

## Speed

- Phone snapshots are encoded off the main thread, and incoming iCloud records
  are verified and classified off it too, so every page opens without waiting
  on sync.
- The bots scheduler no longer rewrites its own file twice a second.

## Look

- The Chat and Access and Policy cards use the same glass as every other card.
  Bot cards sit on a cool slate so they read neutral under the room's warm light.

## Under the hood

- Every account declares whether it can carry tool calls; page reads use a
  quiet reader that needs no browser window and no consent.
- A release-configuration build can be installed locally for real-speed checks.
