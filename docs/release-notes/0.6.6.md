# NativeAgent 0.6.6

First-run fixes on top of 0.6.5.

- Onboarding offers Claude's setup token under Sign in with Claude: run
  `claude setup-token` in Terminal and paste it there. Before, the first run
  only offered the browser sign-in.
- Under Work mode, shell, git and the other file tools show their "Allow file
  access" card up front, instead of asking to run a call that could not run.
- A part's web request reads "Fetch from the web" on its card.
- The Trust presets say what each one does: Work and Builder ask before sends
  or changes on your side, and Mac control, shell and git need Full Mac.
- The chat holds still while the agent works: the live card above the
  composer changes inside its own space instead of pushing the conversation
  up and down.
- Typing right as a chat opens no longer jumps the cursor to the start of
  the box.
- In Simple view, Connectors and the other setup panels sit on a solid
  background, so the chat no longer shows through the text.
