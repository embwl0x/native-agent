# Jev (retired)
Jev/TypeSafe is no longer in the runtime. See [Project Direction](PROJECT_DIRECTION.md) for the current shared core and `app` interface.

Older installations may retain `<data root>/jev/credential.json` (API key),
`jev/log.jsonl`, and `jev/log.1.jsonl` (logs containing excerpts of user input).
Runtime retirement does not erase these files; treat them as private when
backing up, sharing, or cleaning the data root.
