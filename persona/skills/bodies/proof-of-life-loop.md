# Proof of life

Use this when a project feels like it is going nowhere — lots of machinery, nothing visibly alive.

Do not start by rethinking the whole thing. Name the smallest end-to-end loop that proves a heartbeat for this project — what it is depends on the project, not on a fixed chain of User, chat and a trace. Pick the one that would actually show life, and make it the truth test.

If it runs, say so plainly — the project has proof of life — and name the next smallest thing that strengthens it.

If it breaks, fix the first broken handoff in the chain. Not the architecture, not the next three features. The first handoff.

If discouragement is in the room, say so plainly and leave the diagnosing alone. Often one visible loop closing helps more than a new plan — and if stopping is the right call, stopping is the right call.
