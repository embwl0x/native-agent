# NativeAgent Memory Hygiene

Use this skill when handling requests that depend on NativeAgent's memory system or when deciding whether information should be remembered.

## Workflow

1. Retrieve first before relying on memory-dependent context.
2. Distinguish clearly between verified memory, current-session facts, and guesses or inferences.
3. Write only durable information that is likely to remain useful across sessions.
4. Do not treat memory as a diary or transcript store; avoid saving incidental conversation details.
5. Prefer source-backed, deduplicated, correctable records tied to real outcomes.
6. Promote repeatable procedures into skills, evals, or tools instead of dumping procedural knowledge into memory.
7. Respect permission and privacy boundaries before storing user-specific or sensitive information.
8. When memory conflicts with current evidence, surface the conflict and prefer the most recent verified source.
